## Options

(a) The owner, as today: `fixed` is their flip, the same as `shipped`. (b) The agent,
when the landing report clears it.

## Decided

(b). A feature's `shipped` stays the owner's.

## Why

The product owner's choice, 2026-10-24 ("can we change the marking it fixed process so
you decide instead of me?"). A bug's contract is its Repro and Expected, which a report
settles without judgment; a feature's Accept needs the owner's. The owner chose to keep
P56's quote check as a precondition, so code, not only the reporting agent, confirms the
report quotes the bug word for word.

## Reopen if

A bug the agent marked fixed turns out not to be fixed.
