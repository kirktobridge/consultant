## Options

(a) Run the full suite every time: every commit, every close, every landing. (b) Reuse
a passing result for an identical tree (the codification review's D3, drafted as P39).

## Decided

(a): the suite runs every time.

## Why

The product owner's choice, 2026-10-21: the suite is fast here, and every run is a
chance to catch something nobody was looking for. A reused result is a stand-in
that lets a commit through without testing it.

## Reopen if

The suite gets slow enough that waiting on it changes how people work.
