# Open ideas — raw dump

**Human-owned. Read-only for agents** (enforced by `.claude/edit-blocklist`).

This file is deliberately *not* a source of truth. Ideas here may already be shipped,
deferred, dead, or half-thought. That's the point: it's a place to write something down
in ten seconds without deciding what it is yet.

`/triage` reads this, classifies an idea as measurable-vs-buildable, checks it isn't
already tracked, and drafts a proper backlog entry for your approval. Nothing here is
committed to.

Agents don't edit it because "tidying" a raw dump destroys the provenance that makes it
useful — and because an idea silently rewritten by an agent stops being *your* idea.
