## Repro

On 2026-10-27 local, in the evening, run `ship.mjs resolve A-3 verified --from <file>` on a clone of main. The entry gets `resolved: 2026-10-28`.

## Expected

Today's local date.

## Notes

The cause is `new Date().toISOString().slice(0,10)` in ship.mjs; the same expression is
in backlog-schema-check.mjs (its "in the future" check), session-audit.mjs and
export.mjs (verified 2026-10-27 by grep). They must agree, so the fix shares one
`today()`. Harm: a dependent re-read and dated today by hand reads as stale against a
date written as tomorrow.
