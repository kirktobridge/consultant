## Repro

1. Run `node evals/run.mjs --skill land --reps 1`, then `node evals/run.mjs --skill orchestrate --reps 1` within the same second.
2. One run dir holds all 8 prompts, but its `manifest.json` lists only orchestrate's 4.

## Expected

The second emit gets its own directory, or refuses to write into one that exists.

## Notes

Seen 2026-10-24 during P49's baseline. Grading reads the manifest, so the first emit's
reps drop out without an error.
