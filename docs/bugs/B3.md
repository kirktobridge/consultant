## Repro

1. Leave an eval run in evals/runs/ (git ignores it).
2. The link check in tests/process.test.mjs also reads evals/runs/; the suite goes red
   and blocks commits. That's what blocked the ship commit.
3. Moving the run to the session scratchpad
   (/tmp/claude-1000/-home-glamdring-consultant/dc6ee846-4082-4cef-93ea-b9883315002f/scratchpad/2026-10-21T05-54-48/)
   let the commit pass.

## Expected

The suite checks only the tree that git tracks. Files git ignores never change its result.

## Notes

`markdownFiles()` (tests/process.test.mjs) skips .git, node_modules, tests, template/
and nested checkouts, but nothing that git ignores. Checked 2026-10-21 by reading the
walker against .gitignore line 9.

Fixed 2026-10-21 on the user's word (merge 761d074): `markdownFiles()` now skips every
path git ignores. Repro observed not to reproduce and Expected observed, both by tests
before landing (a planted ignored `.md` with a broken link; control with the fix off
failed). No criterion left unobserved.
