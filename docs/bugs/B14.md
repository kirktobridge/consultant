## Repro

1. Main checkout with f.py = "def f():\n    if x:\n        go()\n    done()\n"; worktrees feat/p1-one and feat/p2-two off main.
2. In p2: set line 3 to "    go()", commit. Land it: lock take, rebase, merge, finish.
3. In p1: set line 1 to "def g():" and line 3 to "            go()", commit. lock take, rebase → exit 3, one region on line 3.
4. Resolve the region to main's side only ("    go()") and run `node scripts/land.mjs continue`.
5. It exits 0: "rebased onto main …, with 1 conflict region(s) resolved". p1's re-indent is gone; no case was asked for and no stop was made.

## Expected

`continue` treats the region as one-sided, as it does when the sides differ in more than whitespace: it refuses until the session gives its case, then stops for the owner (D-4).

## Notes

`norm` in land.mjs trims leading whitespace of the joined region, so sides that differ only in indentation compare equal and `differ` is false. Predates P39; found in P39's code review, then reproduced with the real land.mjs on 2026-10-28.
