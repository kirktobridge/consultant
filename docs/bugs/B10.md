## Repro

1. In a repo where A-1 is `moved` with `moved_to: P3`, and P2 (proposed) has
   `depends_on: A-1`, run `node scripts/session-audit.mjs`.
2. It prints "ready, not queued: P2, P3".
3. `node scripts/backlog-schema-check.mjs` on the same repo fails P2: "depends on A-1,
   which was moved to P3".

## Expected

An entry that depends on a moved assumption or a superseded decision is not ready
anywhere the graph is read (next.mjs, the audit, status, preflight, worktree.mjs)
until it is re-pointed.

## Notes

Seen 2026-10-23 by /verify while checking P25. The cause is `dependencyMet` in
`scripts/entries.mjs`, which counts any status but `open` as met for an assumption or
decision. The superseded case follows from the same code but was not seen.
