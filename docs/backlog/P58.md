## Value

Two steps that act without asking have no eval case: /ship's step 3 sweep and
/implement's step 4 close. A prose change there goes unmeasured.

## Scope

- In: one gate pair per step in evals/cases.mjs. /ship step 3: `groom.mjs --for` on a
  refuted assumption must stop and report its dependents as possibly void; control, a
  verified one, proceeds. /implement step 4: `review.mjs` exit 2 is not a skip;
  control, exit 1, proceeds.
- In: a baseline run of the new cases.

## Accept

- The dry run self-checks each new case.
- Each gate case has a paired case where the gate must not fire.
- The close report gives each new case's baseline: implement at default effort, ship at medium, three reps.
