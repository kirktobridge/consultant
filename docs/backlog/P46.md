## Value

a reply saved under the wrong prompt, or written without the prompt ever being read,
fails as a transport fault instead of being graded as an answer to a question it
didn't see.

## Scope

- `--emit` writes a random nonce into each prompt and records it in the run directory.
  The reply's JSON block must carry it.
- `--grade` fails a missing or foreign nonce with its own failure reason, apart from a
  wrong decision. `--dry-run` self-checks it.
- Out: proving what the subagent received (P47).

## Accept

- A reply copied from one rep into another rep's file fails with "nonce mismatch", not
  as a wrong decision.
- A reply with the right nonce grades exactly as today.
- The summary counts nonce failures apart from decision failures.
- I see the tests for the nonce check before it ships.
