## Value

An ad-hoc change that touches an open entry's area moves the code the entry
describes, just as a landed dependency does. Today nothing flags the entry, so the
next build starts from claims that may no longer be true.

## Scope

The schema check reads `Relates:` trailers from ad-hoc merge commits on main. It
flags an open entry when a related ad-hoc merge is dated after the entry's
`drafted:`, with the same meaning as the existing flag: re-verify before you build.
Out: changing what ad-hoc work is allowed to touch.

## Accept

- An open entry named in the `Relates:` of an ad-hoc merge dated after its `drafted:`
  is flagged, and the flag names the merge commit.
- Bumping `drafted:` to that date or later clears the flag.
- An entry with no related ad-hoc merge gets no new flag.
