## Value

P34's ad-hoc staleness flag is a notice: it never fails a check, so it scrolls past in
`npm test` output and the session about to build the entry never sees it. Preflight is
the one step that reads the entry right before the build.

## Scope

- In: preflight prints each ad-hoc staleness notice for the entry it gates, naming the
  merge, as the schema check words it.
- Out: dependency staleness, which is already a violation and cannot sit on main; and
  changing the notice into a failing gate.

## Accept

- An open entry named in the `Relates:` of an ad-hoc merge dated after its `drafted:`
  shows that notice in preflight's output, naming the merge.
- An entry with no such merge shows no notice, and a notice never changes preflight's
  verdict or exit code.
