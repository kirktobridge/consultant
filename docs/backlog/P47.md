## Value

an eval measures the skill's prose only if each subagent got the prompt file unedited
and answered without reading the real repo. Today nothing shows either; it was checked
once by hand.

## Scope

- `npm run eval -- --check-transcripts <run dir>` finds each rep's subagent
  transcript, compares its first prompt record with the prompt file byte for byte, and
  lists any tool calls.
- Where transcripts live and their format are the harness's, observed by hand on
  2026-10-21 (the first record with no parent and string content is the sent prompt;
  tool_use records name the tools).
- Out: changing how reps are dispatched.

## Accept

- A rep whose subagent received an edited or summarized prompt is named, with the
  first differing line.
- A rep whose subagent used any tool is named, with the tools.
- If the transcripts can't be found, the check exits 2 and says where it looked,
  instead of reporting every rep clean.
