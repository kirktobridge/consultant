## Value

Every register's ID is a letter and a number (P5, B2, A3, D1). Nobody has to remember
which registers use a hyphen, and one pattern parses every ID.

## Scope

- Rename `docs/assumptions/A-n.md` → `An.md` and `docs/decisions/D-n.md` → `Dn.md`,
  keeping the numbers (A-3 is A3).
- Rewrite every ID reference in tracked files to the new form, including shipped
  entries (on the user's word, 2026-10-19: historical accuracy of labels is not a
  concern): `depends_on` / `resolves` / `superseded_by` headers, entry prose, register
  READMEs, skills, GUIDE.md, CLAUDE.md, script comments.
- `scripts/entries.mjs` and `scripts/backlog-schema-check.mjs` accept only `A\d+` /
  `D\d+`; the old form becomes a schema failure, in the same commit.
- Each of the assumptions and decisions READMEs gets a one-line note: an `A-n` / `D-n`
  in older commits means `An` / `Dn` (same precedent as the existing `OD-n` note).

## Accept

- `npm run check:docs` passes on the renamed tree, and `docs/assumptions/` and `docs/decisions/` contain `A3.md`…`A12.md`, `D1.md`, `D2.md`, with no hyphenated filenames left.
- An entry whose `depends_on:` names `A-3` fails the schema check, and the message names the old form.
- `node scripts/grep-checked.mjs --control 'A3' '\b[AD]-[0-9]+\b|\b[AD]-n\b'` over docs/, .claude/, scripts/ and CLAUDE.md matches only the two history-mapping notes.
- The session audit still reports the dependents of a verified assumption (today's "A-11 is verified … P15" note reads "A11 is verified … P15").
