## Value

a change to a skill's prose is exactly what the eval measures, and today nothing at
review time says which cases a diff puts in question. The owner decides whether to
run them; code says which.

## Scope

- When the diff touches `.claude/skills/<s>/SKILL.md`, review.mjs adds an advisory
  line naming the skill, its case count and the command to run them. It never changes
  the exit code.
- /implement's close report carries the line. Running the eval stays the owner's
  call; it is never a gate.
- Out: running the eval.

## Accept

- A diff touching the implement skill's SKILL.md prints an eval line naming implement
  and its case count; the exit code is what it would be without the line.
- A diff touching no SKILL.md prints no eval line.
- A diff touching a skill with no cases says it has none, rather than staying silent.
