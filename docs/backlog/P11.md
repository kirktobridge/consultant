## Value

what blocks what is computable from the entries' dependency fields, but
nothing computes it; groom and any status view would re-derive it by hand. A fixed
JSON shape lets one renderer serve every repo running the suite, whatever language
its checker is in.

## Scope

port photocull's `--graph` / `--graph --json` mode to the schema check
(ranked unblocked items, chains, prose blockers; entries, edges with their field,
prose blockers), the same JSON shape pinned by a test. Edges come from the
`depends_on:` and `waiting_on:` headers; a decision waiting on `user` is a prose
blocker. Out: rendering, which is P7; the Feeds/Waiting-on consistency rule and
Feeds edges, which move to P13 with the experiments that carry `Feeds`.

## Accept

- the graph mode lists what can start now, most-unblocking first, and the chain
  behind each blocked item
- its JSON matches photocull's shape, and a test fails if the shape drifts
