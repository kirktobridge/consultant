## Value

/research's START GATE asks whether the planned n can detect the hypothesised effect
at the decision rule's threshold. That arithmetic is the step most likely to be
skipped, and today it is prose: `## Power` and `## Hypothesis` are free text code
can't read.

## Scope

- A `test` experiment's header carries `n:`, `bar:` and `effect:`. The experiments
  README, the schema check and entries.mjs change in the same commit.
- The schema check fails an open test whose minimum detectable share at (bar, n), from
  stats.mjs's own function, is not below `effect`.
- A run committed before the decision rule it is judged by is flagged where git is
  available; where it isn't, the check says so and never passes silently.
- /research's START GATE runs the check instead of computing by hand.
- Out: the `measure` and `probe` kinds.

## Accept

- An open test whose planned n can't detect its effect at the bar fails the check,
  naming the n, the detectable share and the effect.
- A test with enough n passes; one missing any of the three fields fails, naming the
  field.
- A run committed before its decision rule is flagged, naming both commits.
