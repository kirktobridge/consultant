## Value

"what's next" and "the next N" can't disagree about whether an entry is ready.

## Scope

- One function in entries.mjs says what holds an entry: feature dependencies
  through P23's graph, other dependencies as leaves, and a dependency with no entry
  as unmet. Both next.mjs modes call it.
- Single-pick passes over a queued entry that something holds, as --count does,
  and names what holds it.
- Out: reading registers off the trunk (P36).

## Accept

- With a queue of P1 (in-progress), P2 (depends on P1) and P3, `node scripts/next.mjs`
  proposes P3 and says P2 waits on P1.
- `next.mjs` and `next.mjs --count 1` propose the same entry, as the new test
  case checks.
- The existing next.mjs tests still pass.
