## Value

the README's "Try it" block tells a reader which exit code each grep-checked
command returns, and nothing holds those numbers. P20 broke one silently (the
`# exit 1` example began exiting 2) and it was caught by hand. A wrong exit code
in the front door teaches the reader the wrong meaning for 1 and 2, the one
distinction the tool exists to make.

## Scope

- Extend process.test's "README's promised output" test: every line in the Try-it
  block carrying an `# exit N` comment is run and its exit code asserted. The
  edit-guard line counts too.
- Out: asserting the commands' printed output beyond what that test already holds.

## Accept

- Changing the README's `# exit 1` example so it actually exits 2 makes `npm test`
  fail, and the failure names the README line.
- Removing the `# exit N` comments makes the test fail too, rather than passing
  because it found nothing to check.
