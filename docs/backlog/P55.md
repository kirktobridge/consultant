## Value

Claims, flips, resolutions and intake stop being hand edits that can half-land: each
one becomes a single checked commit.

## Scope

Built alone, never in parallel with another build.

- R0: claim. It lands beside the old /ship; callers switch to it only after 2 clean
  real claims.
- R1: terminal flips (`shipped`, `fixed`, a rejection), and the queue-before-entry
  ordering rule goes away.
- R2: resolve an assumption, record a decision.
- R3: ID allocation, and intake from an approved draft file.

## Accept

- `ship.mjs claim <ID>` makes the claim commit on main under the land lock, and refuses a claimed entry, unmet dependencies, or a dirty tree with a message naming why.
- A terminal flip writes the entry and the queue in one commit, and the schema check is green after it; it refuses to commit when the check would go red.
- `shipped` is refused unless the call carries the owner's acceptance flag; `fixed` is refused unless it carries that flag or the landing report clears it (D-7).
- Gate 2: one full claim → land → accept and one rejection run through ship.mjs on real entries, with no hand-fixes to the docs afterward.
