## Value

The owner stops being asked to accept each bug fix (D-7). Bugs stop waiting in
"awaiting acceptance", where the session audit can read them as stale claims.

## Scope

- In: /land's /ship pass flips a landed bug to `fixed` itself when the merged suite is
  green, the report reads the Repro as not observed to still break and the Expected as
  observed (read by code, in close-report.mjs, not by the agent), and
  `close-report --check` is quiet. Any other result leaves it `in-progress` and asks the
  owner, as today.
- In: the owner can reopen a bug /land marked fixed: it goes back to `in-progress`, with
  the date appended to `rejected:`.
- In: the rule changes together in the /ship, /land and /orchestrate skills, the bugs
  README and session-audit's messages; P55's `fixed` condition follows it.
- Out: a feature's `shipped`.
- Out: a fix whose report predates a conflict resolution; it stays with the owner.

## Accept

- A bug whose landing report says the Repro no longer breaks and the Expected is observed, with a green merged suite, is `fixed` on main when /land finishes. You aren't asked.
- A bug with any other verdict stays `in-progress`, and /land asks you, as today.
- Features still wait for your `shipped`.
- You can reopen a bug /land marked fixed, and `next.mjs` then shows it as being built again.
