## Value

A decision rule edited to fit a result already in hand gets flagged. Today the check
P45 added reads only the commit that first added the `## Decision rule` heading.

## Scope

- In: the run-order check compares the run's commit with the last commit that changed
  the rule's text, not only the heading's first commit.

## Accept

- A `## Decision rule` whose text changed after a run's commit is flagged, naming the edit's commit and the run.
- A rule left unchanged after the run is not flagged.
