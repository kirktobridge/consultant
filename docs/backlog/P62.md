## Value

A settling flip and the re-read it forces land together, so `drafted:` is never bumped
before the change it was re-read against exists.

## Scope

A repeatable `--reread <ID>` on `shipped`, `fixed`, `resolve` and `decide`: each named
open dependent gets `drafted:` today in the same commit. A stale dependent the call
doesn't name is still refused, as now.

## Accept

- A flip that names every stale dependent with `--reread` makes one commit holding the entry, those dependents and the queue, and the schema check is green.
- A flip that leaves a stale dependent out of `--reread` is refused, names it, and changes nothing.
- `--reread` on an entry that doesn't depend on the flipped one is refused.
