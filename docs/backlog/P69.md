## Value

Rescoping an entry on the owner's word is a hand edit on main today: Scope, Accept
and Notes rewritten, `drafted:` bumped, the queue maybe regenerated, all outside the
land lock and with no check that the owner's words were recorded. Accept is the
owner's definition of done, so it is the one edit where a missing record matters most.

## Scope

- In: `ship.mjs rescope <P#|B#> --owner "<their words>" --from <draft>`. The draft
  holds the entry as rewritten. In one commit under the land lock: replace the entry's
  body and header from the draft, set `drafted:` to today, append a dated Notes line
  with the owner's words, regenerate QUEUE.md, run the schema check, or put every file
  back.
- In: it refuses a draft that changes `id:` or `status:` (those have their own
  commands), and a rescope without `--owner`.
- In: /ship's prose names the command where it now describes the hand edit.
- Out: the partial-milestone flip; deciding what the new text says.

## Accept

- `ship.mjs rescope P# --owner "…" --from <draft>` makes one commit on main with the new text, today's `drafted:`, and a dated Notes line quoting the owner's words.
- A draft that changes `id:` or `status:`, or a call without `--owner`, exits 1 and leaves the entry unchanged.
- A draft the schema check rejects exits 1 and leaves every file as it was.
- /ship's prose points to this command for a rescope, not to a hand edit.
