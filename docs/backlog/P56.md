## Value

A bug fix's report gets the same verbatim check a feature's does. Today `--check` on a
bug says its Repro and Expected are not checked, and passes.

## Scope

- In: `scripts/close-report.mjs --check B#` compares the report with the bug's Repro
  and Expected on the trunk, as it does a feature's Accept.
- Out: changing the skeleton it prints for a bug.

## Accept

- `--check B#` warns when the report changes or drops the bug's Repro or Expected text, naming which.
- It is quiet on a report that quotes both word for word.

## Notes

A follow-up to P44, which added `--check` for features only. Plan: no — one script and its tests.
