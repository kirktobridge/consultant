## Value

The owner accepts against /land's handshake, and /land assembles it from prose on every
landing: tokens spent each time, and a criterion can still be lost or reworded at the
last step. Code can copy every part of it.

## Scope

- In: a script, handshake.mjs, prints /land's acceptance handshake for a branch: each
  criterion word for word from the entry on main with the report's verdict and
  evidence, not-observed and not-exercised ones first, `close-report --check`'s result,
  the conflicts from `land.mjs report`, the review line as review.mjs prints it, and
  the closing question. /land relays it and adds only its own after-landing verdicts.
- Out: refusing a landing whose report fails the check (dropped 2026-10-29: the check
  has never warned on a real landing, so a refusal guards a case not yet seen); judging
  whether the evidence holds.

## Accept

- /land's handshake quotes every criterion word for word from the entry on main, with the verdict and evidence from the branch's report, not-observed and not-exercised ones first.
- /land's prose for the handshake points to the script instead of listing its parts.
