## Value

a duplicate is caught by meaning, not by whether I guess the keyword the first author
used. Today /triage's keyword search runs after classifying, and a reworded idea
passes as new.

## Scope

- `scripts/titles.mjs` prints ID, status and title for every entry in every
  register, read through entries.mjs. A register it can't read makes it exit 2,
  never print a shorter list.
- /triage reads the whole index as its first step, before classifying, and names the
  closest existing entries or says none is close. The keyword search stays as the
  second look.
- Two paired eval cases: a reworded duplicate, and a genuinely new idea.
- Out: fuzzy matching or similarity scores in code (a syntactic proxy may flag a
  duplicate, never clear one).

## Accept

- Every entry in every register appears in the index with its current status and
  title; an unreadable register makes it exit 2 rather than print a shorter list.
- Given an idea reworded from an existing entry's title with none of its keywords,
  /triage names that entry as already tracked.
- A genuinely new idea still gets drafted; the index doesn't make triage call
  everything a duplicate.
