## Value

A build is claimed (`ship.mjs claim`) and then given its worktree (`worktree.mjs
start`) in two steps. When the second fails, or the session stops between them, main
holds a claim no branch builds: the abandoned claim that keeps everyone else off the
entry until someone notices.

## Scope

- In: one command that, under one land lock, runs preflight's gates, commits the
  claim and cuts the worktree. If the worktree can't be made, the claim commit is
  undone before the lock is released. It prints the worktree's path, as worktree.mjs
  does now.
- In: /implement's and /orchestrate's set-up steps use it.
- Out: resuming an existing claim (P52).

## Accept

- On success, one command leaves main with the claim commit and the entry's branch and worktree in place.
- When the worktree step fails (a test can force it, for example with the worktree path already taken), main has no claim commit afterwards and the entry is still `proposed`.
- When preflight refuses, nothing is committed and no worktree exists.
