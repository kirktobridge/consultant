## Value

/implement's step-1 gates (claim, depends, milestone, spike, premise) are run by hand
from prose at the start of every build, and a misread gate fails silently. Preflight
already gives the answer from the docs and git; once its verdicts have matched the
manual gates, it should be the gate.

## Scope

- In (after the agreement gate, program Phase 3): preflight becomes the gate, and the
  prose for those gates in /implement shrinks to a pointer.
- Out: judging whether a behavioral claim holds.

## Accept

- (R1) /implement refuses to start when preflight exits non-zero, without re-running
  the gates by hand.
- /implement's text for the gates preflight runs points to preflight instead of
  describing each gate again.
