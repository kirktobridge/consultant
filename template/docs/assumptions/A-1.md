## Assumption

this project has at least one load-bearing fact nobody has checked yet: a
third-party API's real rate limit, a constant taken on trust, "users won't do X".

## Why it matters

an `open` assumption blocks every entry that depends on it from being queued or
claimed. That only helps if the register holds the real ones; see PORTING.md, step 3.

## How to verify

list what your project currently assumes, file each as its own `A-n`, then delete
this file. The schema check refuses an empty register.
